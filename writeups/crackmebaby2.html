CrackMeBaby2

📅 May 2026 🏆 crackmes.one — igr0t7 🔖 Reverse Engineering

Overview

CrackMeBaby2 is a short two-stage crackme. The first stage hides the real password behind a fake flag and a simple XOR check, and the second stage asks for the author's name.

Binary: CanYouCrackMeBaby2.exe  |  Arch: x86-64 PE (Windows)

Step 1 — Avoid the Anti-Debug

The binary checks for common debugger processes before doing anything else. I avoided that by staying in static analysis and reading the logic in IDA instead of stepping through it.

Step 2 — Find the Real Check

I searched for "Input the pass:" in the Strings window and followed the cross-reference into main. The first comparison looks like the answer, but it is only bait: 

if (len == 20 && !memcmp(input, "flag{can-you-crack?}", 20))

If you enter that string, the program still says "Access Denied", so the real path is elsewhere.

Step 3 — Reverse the XOR

The real check XORs the input with 0x0A and compares it to a stored string. 

for (i = 0; i < len; i++)
    input[i] ^= 0x0A;
if (len == 18 && !memcmp(xored_input, "lfkm0cmx:~'~boacdm", 18))

Since XOR can be reversed with the same key, I decoded the stored value and got the real password: 

>>> ''.join(chr(ord(c) ^ 0x0A) for c in "lfkm0cmx:~'~boacdm")
'flag:igr0t-theking'

Password: flag:igr0t-theking

Step 4 — Answer the Second Prompt

After the password, the program asks one more question: 

Say my name...

This check is simple. The answer is just the author's handle: igr0t. 

if (len == 5 && !memcmp(input2, "igr0t", 5))
    print("You Win.. (;");

Result

Input the pass: flag:igr0t-theking
You are good , but...
Say my name... igr0t
You Win.. (;

Key Takeaways

  • Check the real code path instead of trusting the first flag-looking string you see.
  • Simple XOR protection is easy to reverse once you find the key.
  • Some crackmes use a second prompt to make sure you actually followed the full flow.
